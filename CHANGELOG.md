# Changelog

## 0.1.0

Initial release.

- Changes list in the activity bar for the working tree, a branch against its base, or two refs.
- Opens changes in VS Code's diff editor at the first change, or all changes in the multi-diff editor.
- Keyboard navigation between files and changes, wrapping across files.
- Mode picker for branches, tags, and recent commits.
- `qd` terminal command that opens QuickDiff for the current repository.
- Working tree list refreshes on file changes.
